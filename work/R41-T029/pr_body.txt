## Description

Implements and verifies a stated, modality-appropriate **robustness property** for the **Goodbooks-10k – content-based recommender** interface (`course-labs/r41-t029`). Using the six-interaction synthetic fixture with leave-last-out splitting (reserving each user's final interaction for held-out validation/test splits), this lab verifies:

1. **Valid transformation**: Inter-user record-order permutation that strictly preserves each user's chronological `user_seq` order (never randomizing within-user time order) produces bit-identical splits, held-out scores, and top-2 recommendations after `(user_id, item_id)` alignment.
2. **Forbidden/unsupported inputs**: Reversing within-user time order raises `TimeOrderViolationError`; missing required fields (`user_id`, `item_id`, `rating`) or invalid ratings raise `SchemaValidationError`; unseen users, unseen items, and items with all-unseen content tokens map to explicit `ScoreResult(is_fallback=True, score=0.0, fallback_reason=...)`.

Explicitly scoped to interface invariance and fallback behavior — does **not** claim broad adversarial robustness.
