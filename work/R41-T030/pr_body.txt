## Description

Implements and verifies a safe JSON **saved-model save/reload and inference interface** for the **Global CO2 emissions – trend forecast** teaching component (`course-labs/r41-t030`). Fits a deterministic closed-form OLS linear trend strictly on chronological training observations (`d1..d6`, no shuffling), persists configuration and parameters as validated JSON (`saved_model.json`, explicitly rejecting untrusted `.pkl`/`.pickle` formats), and exposes `predict_with_artifact()` requiring no training data or credentials at inference time.

Before-save and after-reload predictions agree within explicit tolerance (`RELOAD_TOLERANCE = 1e-12`, observed `0.0`), while schema/version mismatches, pickle formats, shuffled timestamps, and malformed inference payloads fail clearly.
