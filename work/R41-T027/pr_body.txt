## Description

Implements and verifies a strict, serializable experiment configuration and bounded linear SVM verification pipeline for the **Banknote authentication – SVM** teaching component (`course-labs/r41-t027`). Captures `schema_version`, `task_id`, `seed`, `feature_ordering`, `valid_labels`, explicit `split_ids` (`train`/`validation`/`test`), and SVM `algorithm` settings in JSON, and guarantees that reloading the serialized configuration reconstructs the exact same splits, learned weights, and predictions while recording runtime environment versions.

Unknown fields (at top level, in `split_ids`, or in `algorithm`), unsupported schema versions, contradictory settings (such as `kernel="linear"` with non-null `gamma`, `kernel="rbf"` without positive `gamma`, `name="linear_svm"` with non-linear kernel, or overlapping `split_ids`), and incompatible input shapes are explicitly rejected.
