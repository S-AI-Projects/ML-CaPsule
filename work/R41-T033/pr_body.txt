Description
Implements the simplest honest baseline (training-mean predictor) for the Palmer penguins – logistic regression teaching fixture. The baseline calculates the target mean exclusively from training records (r1..r4) and evaluates predictions and MAE on held-out validation and test rows without using any test data for parameter estimation.
