Description
Implements a strict schema validator for image input fields (`record_id`, `group_id`, `pixels`, `label`) for the MNIST – k-NN baseline teaching component. Validates unique identifiers, non-empty text, numeric labels, and 4×4 image tensor bounds without silently dropping records. Includes a 6-row synthetic smoke fixture and a bounded CPU-only k-NN baseline.
