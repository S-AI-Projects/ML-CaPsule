## Description

Implements and verifies a bounded, offline, CPU-only regression pipeline smoke test for the **Building energy efficiency – regression** teaching component (`course-labs/r41-t026`). Enforces strict smoke-test bounds (`<= 32` samples, fixed seed `42`, `<= 1` training epoch, and `<= 20` gradient update steps) and asserts interface correctness — finite outputs and MSE/MAE losses, exact prediction shapes `(n_samples,)` with `dtype="float64"`, recorded step count, deterministic reproducibility, and explicit train/validation/test separation — rather than useful predictive accuracy.

Includes both a tiny 1-epoch / 4-step CPU linear SGD smoke model (`BoundedLinearSGDSmokeRegressor`) and an explicitly labelled constant/naive training-mean baseline (`NaiveMeanBaseline`, `is_naive_baseline=True`).
